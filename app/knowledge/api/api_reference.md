## Conventions (from the Swagger `info.description`)

- **Envelope.** Every response is `{code, msg, data, total, extend}`; `code` equals the HTTP status.
- **Vendor data.** Vendor-backed reads report their source in `extend` (`source` VENDOR or LOCAL, `stale`, `fallbackReason`, `message`). When the vendor (GPSTrackTech) returns no data, `msg` and `extend.message` are "No data from vendor" and `extend.fallbackReason` is `VENDOR_EMPTY`. When stored data is served instead, `source` is LOCAL and `stale` is true.
- **Errors.** `extend` is `{errorCode, fieldErrors[], requestId}`; `requestId` equals the `X-Request-Id` header. 400 validation/invalid value · 401 missing or expired token · 403 missing permission · 404 not found (also for records of another tenant) · 409 conflict or transition not allowed · 502/503/504 vendor or database problems · 500 unexpected.
- **Times.** ISO-8601 UTC. Ranges are `[from, to)`; a missing `to` means now. Plain dates are UTC dates.
- **Paging.** `pageNumber` starts at 1; `pageSize` 1–100 (default 20); `total` counts all matching records.
- **Access.** Every record is scoped to the caller's tenant. The Safe-Fare Admin (signs in without `tenantCode`) has no tenant: it must send `?tenantId=` or `X-Tenant-Id` on create/update/delete (else 400 `TENANT_REQUIRED`); its reads without it cover every tenant. Tenant users may omit it; another tenant's id answers 403 `TENANT_ACCESS_DENIED`. `/api/v1/driver/**` requires a user linked to a driver profile and only returns that driver's data.
